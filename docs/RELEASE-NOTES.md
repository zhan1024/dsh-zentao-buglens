# 禅图 BugLens v0.1.0

面向测试同事的截图提单工具，提供两项独立交付：

- **DSH 插件**：npm 包 `dsh-zentao-buglens`，注册 10 个 `buglens_*` 工具。
- **Agent Skill**：`zentao-buglens`，可独立安装到 Codex、Claude Code 等标准 skills 目录，提供独立 ZIP。

配套 Chrome/Edge 扩展支持当前业务页面截图，以及可选的后续操作、控制台和请求取证。工作台支持多图粘贴、圈选、AI 推荐问题、预期确认、前后端排查分工和本人最近指派推荐。提交时创建一个主负责人 Bug，上传原图、圈选图、Markdown 与含图 HTML 材料，并回读正文。

创建与上传状态落盘，超时先核实再恢复，避免重复建单。未采集证据保持未知，不把 AI 判断当成最终根因。

需要配置支持识图和 JSON 输出的团队模型网关及个人禅道登录。集成验证使用模拟模型/禅道服务，真实 Chromium 扩展和真实 DSH；私有禅道的字段、权限和版本请先在授权测试环境验收。

浏览器扩展通过已解压安装包使用；本 Release 不表示已获 Chrome/Edge 商店审核。
